# 感想ノート — 本・映画・美術館 感想メモPWA

## ファイル構成
- `index.html` … アプリ本体（これ1枚でも動作）
- `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png` … PWA用（ホーム画面追加・オフライン対応）

## 公開手順（GitHub Pages・無料）
1. GitHubで新規リポジトリ作成（例: `kansou-note`、Public）
2. 上記5ファイルをアップロード
   - コミットsummary例: `feat: 感想ノートPWA 初回リリース (v1)`
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 数分後 `https://<ユーザー名>.github.io/kansou-note/` で公開
5. スマホでURLを開き「ホーム画面に追加」→ アプリとして起動

※ もっと手軽な方法: https://app.netlify.com/drop にフォルダをドラッグするだけでも公開できます。

## 機能
- 本📖・映画🎬・美術館🖼️の感想記録（評価・引用・タグ・検索・並び替え）
- 詳細画面タブ: 感想 / Wikipedia（概要・画像を自動取得）/ 口コミ（𝕏いいね多数の投稿検索＋各口コミサイト）/ 関連リンク（Amazon・楽天）
- 設定でAmazonアソシエイトタグを登録 → 関連リンクが自動でアフィリエイトリンク化
- 𝕏はボタン一発で投稿画面へ。noteは整形文コピー→新規記事ページを自動で開く
- ✨AI文章整形: 内蔵テンプレート（X短文/note記事）。設定でClaude APIキーを入れると本格AI整形
- データは端末内保存。設定画面からJSONエクスポート/インポート（機種変更時の移行用）

## 注意
- 口コミサイトの「いいね順API」は各社非公開のため、𝕏は `min_faves:50` 検索、他サイトは作品検索ページへのリンクで代替しています
- note・Xの自動投稿APIは審査/有料のため、Web Intent＋コピー方式を採用（審査不要・確実）
